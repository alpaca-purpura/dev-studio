# DevHub

Aplicación de escritorio multiplataforma para **construir y mantener software basado en
proceso y arquitectura** — proceso as code, arquitectura as code, documentación as code.

Usuarios (CTO · developer · devops · product owner) trabajan **orquestados** dentro de una
organización, a la par sobre uno o varios sistemas, con el repositorio GitHub como conector.

- Visión: [`VISION.md`](./VISION.md)
- Decisiones: [`LEDGER.md`](./LEDGER.md) (fichas `DH-NN` — historia DH-01..DH-11 en la
  incubadora `prenter-harness`)
- Épica activa: [`epicas/experiencia-orquestada/`](./epicas/experiencia-orquestada/)
